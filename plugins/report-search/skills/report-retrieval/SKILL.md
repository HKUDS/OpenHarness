# 报表检索工作流（report-search 插件）

按以下步骤找报表：

1. **提炼检索意图**：从用户问题中提取指标/主题词，并扩展同义词（如 营收→收入/营业收入；DAU→日活）。
2. **检索**：调用 `report_search(query=检索式, top_k=5)`（插件内部调用 MCP「报表检索」服务的 `search` 工具，无需另选 MCP 连接器）。
3. **结果不足时改写重试**：换同义词、换表述再检索，最多再试 2 次。
4. **呈现结果**：每条报表列出——名称（附链接）、核心指标、业务描述；并说明为什么匹配用户问题。

诚实原则：无相关结果时如实告知并建议换关键词，不编造报表名称或链接。
