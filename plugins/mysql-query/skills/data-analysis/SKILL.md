# 数据分析工作流（mysql-query 插件）

按以下步骤回答数据问题：

1. **定位数据库**：调用 `db_list` 查看数据库目录，根据问题描述选择最相关的库（依据 description）。
2. **确认结构**：调用 `db_schema(db_id=...)` 查看表与列；表多时可传 `table` 过滤。不要凭空猜表名列名。
3. **生成 SQL**：先说明推理（用哪些表、如何关联/过滤/聚合），再给出 SQL。仅允许单条只读 SELECT/WITH。
4. **执行与修正**：调用 `db_query(db_id, sql)`。若返回 is_error：读错误信息，修正表名/列名/方言后重试，最多 3 次。
   - 结果被截断（truncated=true）时，改写为聚合/分组查询而非取全量。
5. **输出报告**：用中文输出结构化分析——结论先行；关键数字；markdown 表格呈现核心结果；数据局限说明（如行数截断、时间范围）。

诚实原则：查不到就明说，不编造数据；口径不确定时明确标注假设。
